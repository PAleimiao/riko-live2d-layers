## ⚠️ 重要说明

### 这是 AI 自动拆分，**不是完美分层**！

- 边缘可能有锯齿/毛边，需要手动精修
- 遮挡部分（如头发遮挡眼睛）需要手动补全
- 部分图层可能有重叠或遗漏
- **建议导入 Photoshop / Krita 后人工检查和修正**

### 推荐后续步骤

1. **导入 Photoshop / Krita**
2. **检查每个图层的边缘**，用橡皮擦/蒙版清理
3. **补全被遮挡部分**（如头发后面的眼睛、耳朵后面的头发等）
4. **按 Live2D 规范命名图层**（参考 GPT 给的 PSD 分层需求）
5. **导入 Live2D Cubism Editor 开始建模**

## 🛠️ 拆分方法

- **抠图**: OpenCV Chroma Key（绿幕色键）
- **分层**: HSV 颜色阈值 + 连通域分析
- **工具**: Python + OpenCV + Pillow
